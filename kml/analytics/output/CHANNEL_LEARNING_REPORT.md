## Methodology

- Each playlist is an independent cumulative path.
- The global path follows educational order: Grade 1–6 kanji → post-elementary kanji → grade compounds → post-elementary compounds (Vol. 1, then Vol. 2) → Japanese Vocabulary → Foundations.
- JLPT word coverage = unique curriculum words present in that level's word list ÷ list size.
- Spoken-frequency coverage uses OpenSubtitles 2018 Japanese lemmas (UniDic), band size as denominator.
- Joyo coverage = unique joyo kanji introduced ÷ 2,136.
- Exposure / encounter = distinct videos containing the item (one count per video).
- Learning value per video = new items + reinforced items (kanji + vocabulary). Stars are magnitude bands, not rankings. JLPT / spoken gains are coverage deltas caused by that video.
- Review opportunities: items introduced ≥ 3 lessons ago that have not reappeared.
