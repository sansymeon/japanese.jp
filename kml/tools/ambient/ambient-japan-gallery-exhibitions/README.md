# KML Ambient Japan — Gallery Exhibitions

**Textless family.** Image-only ambient viewing; no kanji or verse overlays.

| Folder | Format |
|---|---|
| `quiet-cinematic/` | Quiet Cinematic five-lesson exhibitions (~50 min) |
| `ambient-movies/` | Ambient Movie compilations (curated ~20-lesson films) |

Recorded MP4s are local-only (`*.mp4` is gitignored). Collection JSON stays in `collections/`.

Related textless films that are **not** Quiet Cinematic or Ambient Movie stay in their current homes until they get an explicit place:

- `heart_exhibitions/` — Heart 2 / Hearts Collection
- `collections/ambient_gallery_japan_4_seasons/` — Four Seasons
